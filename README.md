# MatekTutor v2.0

A 9. évfolyam első teljes tanulási témakörének webes prototípusa.

## Benne van
- K01–K06: Kombinatorika és halmazok
- 42 gyakorlófeladat, fokozatos segítséggel
- 12 önálló ellenőrző feladat
- témaköri Mesterfeladat fájlfeltöltési prototípussal
- tanári témaköri áttekintés

A helyi állapot egyelőre localStorage-ban él; valódi felhasználókezelés és Supabase később kerül be.

- Új, tanulóközpontú magyarázati szerkezet: felfedezés → fogalomépítés → vezetett gondolkodás → gyakorlás → önálló ellenőrzés.
- Új, gazdagabb vizuális arculat és mobilra reagáló layout.
